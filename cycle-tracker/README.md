# Кисунчик 💜 — PWA трекер цикла

Современное PWA-приложение для отслеживания менструального цикла в стиле Flo, сделанное специально для двоих.

## Что умеет

- **Фазы цикла** — автоматически определяет менструацию, фолликулярную, овуляцию и лютеиновую фазу
- **Советы** — планы на день, практические советы и подбадривание (с «кисунчиком» вместо «друзей»)
- **Дневник** — симптомы, выделения, половые акты, настроение, заметки
- **Мигрени** — отдельный раздел: болела/не болела + препараты (Нурофен, Эскенза 1/2 пшика, другое)
- **Календарь** — визуализация цикла и записей
- **Удаление** — можно удалять ошибочные записи
- **Админ** — ты (кисунчик) видишь все записи девушки
- **Темы** — чёрная и фиолетовая (liquid glass)
- **Напоминание** — в 20:00 (через Notification API)
- **PWA** — устанавливается на домашний экран, работает офлайн

## Как запустить

### 1. Локально (без Firebase) — уже работает

Просто открой `index.html` через любой локальный сервер:

```bash
cd cycle-tracker
npx serve .
# или
python3 -m http.server 8080
```

Данные сохраняются в `localStorage`.  
При входе выбери роль: **Девушка** или **Кисунчик (админ)**.

### 2. С Firebase (рекомендуется для синхронизации)

1. Создай проект на [console.firebase.google.com](https://console.firebase.google.com)
2. Включи **Authentication → Email/Password**
3. Создай **Firestore Database**
4. В `js/firebase-config.js`:
   - Вставь свой `firebaseConfig`
   - Поставь `USE_LOCAL_FALLBACK = false`
5. Правила Firestore — скопируй из комментария в том же файле
6. Задеплой на Firebase Hosting / Vercel / Netlify / любой хостинг с HTTPS (PWA требует HTTPS)

### 3. Иконки PWA

Все иконки уже лежат в папке `icons/`:

- `icon-72.png` … `icon-512.png`
- `apple-touch-icon.png`

Они подключены в `manifest.json` и `index.html`.
